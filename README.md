# Muhaiminul Islam Tafsir — 3D Personal Portfolio & Resume Website

A modern, highly interactive **3D personal portfolio and digital resume website** for **Muhaiminul Islam Tafsir**, Software Engineer & Machine Learning Specialist (B.Sc. in CSE from IUBAT University).

Built with **React 19**, **TypeScript**, **Three.js**, **Tailwind CSS**, and **Vite**.

## 🌟 Key Highlights & Features

- **Apple-Level Minimalism + Modern 3D Depth**: Dark cinematic theme with glassmorphism (`backdrop-blur-xl`), glowing accents, and elegant typography.
- **Interactive Three.js 3D Background**: Real-time WebGL particle constellation and ambient floating geometric nodes with smooth mouse-tracking parallax.
- **3D Hero Portrait Card**: Interactive 3D perspective tilt reacting to cursor coordinates, dynamic specular glare, verified CV badge, and authentic handwritten signature.
- **Recruiter-Friendly Architecture**:
  - **Hero Section**: Verified title, brief overview, primary CTA to explore projects, secondary CTA to download PDF resume with celebratory confetti animation.
  - **About Me**: Visual breakdown of academic foundation (IUBAT CSE), applied machine learning, software engineering, teamwork, and language proficiencies (Bengali, English, Hindi).
  - **Experience & Timeline**: Academic and practical engineering milestones, EDGE Project government certified training, responsibilities, and tooling.
  - **Featured Projects Showcase**: Real projects with interactive 3D cards, category filtering (*All*, *Machine Learning*, *Software Apps*), repository links, and expandable technical architecture deep-dive modals:
    1. **Quick Tutor** — Real-time interactive online learning & session scheduling platform.
    2. **Heart Attack Risk Prediction** — Clinical data classification models for early cardiac risk detection.
    3. **Student Depression, Anxiety & Stress Prediction** — Multivariate ML and statistical analysis on university student mental health data.
    4. **Age Calculator Desktop Application** — Precision desktop GUI application engineered with PyQt5.
  - **Skills Matrix**: Categorized according to the resume into Programming Languages, Machine Learning & AI, Core Engineering, Developer Tools, and Personal Leadership competencies.
  - **Education, Certifications & Faculty References**: Verified degrees with GPAs (IUBAT CGPA 3.29 / 4.00, Tongi Gov't College GPA 4.92 / 5.00, A.M. High School GPA 4.73 / 5.00), EDGE certification, and direct contact details of department chairman and coordinator.
  - **Contact Section**: One-click email copy with clipboard feedback, direct phone/location, social/GitHub links, and interactive message form.
  - **Download Resume Button**: One-click download of the official resume PDF (`Muhaiminul_Islam_Tafsir_Resume.pdf`).

## 🚀 Getting Started Locally

### Prerequisites

- Node.js (v18 or higher, Node v24 recommended)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/muhaiminul-tafsir/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:5173/` in your browser.

### Building for Production

```bash
npm run build
```

The production assets will be generated in the `dist/` directory, ready to deploy to any static host (Vercel, Netlify, Cloudflare Pages, or GitHub Pages).

---

## 🚢 Deployment

### Deploy to Vercel
```bash
npm install -g vercel
vercel
```

### Deploy to Netlify
Drag and drop the `dist` folder into the Netlify dashboard, or link your GitHub repository.
